# achiSniper

Automated section sniper for DLSU ArchersHub / Enlistment portal.

## Overview
Automates the enlistment loop:
1. Target Subject and Section selection.
2. Step 1 Enlistment navigation.
3. Step 2 Wizard step.
4. Row detection, checkbox validation, and Select2 section selection.
5. If section is unavailable, loops back to Step 1.
6. If section is available, selects section and clicks Save & Next.
